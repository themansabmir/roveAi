## Brand & Style

This design system embodies high-velocity GTM (Go-to-Market) engineering coupled with deterministic enterprise AI. The brand personality balances executive poise with deep technical credibility: sharp, strategic, architectural, and hyper-precise. It directly rejects playful consumer abstractions in favor of high-performance infrastructure aesthetics, computational clarity, and editorial rigor.

The visual style blends modern corporate minimalism with technical high-fidelity systems:
- Dark, atmospheric viewport frames and data visualizers grounded in deep nocturnal space.
- Crisp, luminous content stages using cool-slate canvases to maximize daylight readability for complex data and strategic messaging.
- Refined structural boundaries using sub-pixel borders, precision micro-grids, and controlled directional luminescence (subtle data glows) to signify active intelligence.
- High-contrast typography pairing modern, authoritative geometric sans-serif structural elements with deliberate italicized editorial serifs/accents to convey strategic leadership.

## Colors

The core palette functions through a deliberate dual-tier hierarchy: dark structural foundations offset by razor-sharp accent vectors and high-clarity document canvases.

### Palette Architecture
- **Midnight Foundations (Neutral Base):**
  - Void Canvas: `#070A11` (Deepest backdrop, terminal wells, canvas boundary)
  - Surface Neutral: `#0B0F19` (Default base background for dark viewports)
  - Elevated Container: `#0F172A` (Card bases, layered architecture frames)
  - Slate Accent / Border Base: `#1E293B`
- **Signal Accents (Electric Vector & Intelligence):**
  - Primary (Electric Blue): `#3B82F6` (Interactive defaults, primary calls to action, directional data flows)
  - Primary Dark / Hover: `#2563EB`
  - Secondary (Electric Indigo): `#6366F1` (System logic, integration nodes, state transitions)
  - Tertiary (Hyper Violet): `#8B5CF6` (AI synthesis states, optimization triggers, premium indicators)
- **Document & High-Clarity Canvas (Light Inversions):**
  - Canvas Light: `#F8FAFC` (Clean white-slate ground for long-form case studies and workflow diagrams)
  - Surface Subdued: `#F1F5F9` (Nested modules within light panels)
- **Precision Stroke & Borders:**
  - Dark Surface Boundary: `rgba(255, 255, 255, 0.08)`
  - Active Data Border: `rgba(59, 130, 246, 0.35)`
  - Light Surface Boundary: `rgba(15, 23, 42, 0.08)`

## Typography

The typography structure orchestrates three roles:
1. **Primary Structural Voice (Plus Jakarta Sans):** Handles headlines, displays, and structural landmarks. Tight letter-spacing gives an engineered, contemporary poise.
2. **Deterministic Engine (Inter):** Powers long-form interface descriptions, data summaries, and core user-facing copy for unyielding legibility across dark and light modules.
3. **Architectural Notation (JetBrains Mono):** Drives metadata tags, API logs, system latency counts, metrics badges, and pipeline stages. Always uppercase for badges, standard casing for parameters.
4. **Editorial Counterpoint (Newsreader):** Interspersed sparingly within hero statements and strategic callouts (e.g., italicized terms emphasizing revenue acceleration or platform autonomy) to introduce human intellect into technical rigor.

## Layout & Spacing

The layout philosophy follows a rigid, 12-column architectural fluid framework contained within a max-width envelope of 1440px.

- **Desktop (>=1280px):** 12 columns, `2rem` gutters, outer margin scaling up to `6rem`. High use of asymmetric pairings (e.g., 5-column technical narrative beside a 7-column real-time pipeline schematic).
- **Tablet (768px - 1279px):** 8 columns, `1.5rem` gutters, `3rem` margins. Modules reflow into stacked horizontal cards; secondary data panels convert to swipeable tabs or collapsible segments.
- **Mobile (<768px):** 4 columns, `1rem` gutters, `1.5rem` outer canvas padding. Full vertical stack. Technical architecture diagrams degrade gracefully to linear node lists.

Vertical rhythm relies strictly on the `space-*` scale to maintain disciplined spatial intervals. Elements within components strictly use `space-xs` through `space-md`, while section separation demands `space-2xl` to `space-3xl` for high-end whitespace management.

## Elevation & Depth

This design system avoids heavy drop shadows, instead communicating depth through tonal layering, sub-pixel borders, and subtle, directional luminance.

### Depth Hierarchy
1. **Canvas (Ground 0):** Hex `#070A11` or `#0B0F19`. Flat, non-reflective base plane.
2. **Structural Layer (Level 1):** Hex `#0F172A` with a micro-border `rgba(255, 255, 255, 0.08)`. Used for master containers and primary stage segments.
3. **Elevated Nodes & Modules (Level 2):** Hex `rgba(15, 23, 42, 0.85)` with backdrop-filter blur (`12px`) and stroke `rgba(255, 255, 255, 0.12)`.
4. **Active Vector Glows:** High-value elements (selected pipeline nodes, key conversion signals) project a controlled, ambient back-glow:
   - Primary Data Glow: `0 0 32px -8px rgba(59, 130, 246, 0.25)`
   - Autonomous Node Glow: `0 0 40px -10px rgba(99, 102, 241, 0.2)`
   - Hover Elevation: Subtle translate-y (`-2px`) combined with border intensification from `rgba(255, 255, 255, 0.08)` to `rgba(59, 130, 246, 0.5)`.

## Shapes

The shape system leverages large structural corner radii (`rounded-2xl` at 1rem / 16px and `rounded-3xl` at 1.5rem / 24px) for parent frames and cards, combined with tight micro-radii or full-capsule pill shapes for interactive controls.

- **Primary Canvas Cards & Containers:** `rounded-2xl` (1rem / 16px) or `rounded-3xl` (1.5rem / 24px). Provides a polished framing device around technical telemetry.
- **Micro UI & Interactive Modules (Buttons, Inputs, Nested Cells):** `rounded-lg` (0.5rem / 8px). Maintains crisp, precise alignment with data grids.
- **Status Indicators, Metadata Tags & Action Chips:** Pill-shaped (`rounded-full` / 9999px) to establish immediate visual differentiation from content containers.

## Components

### Buttons
- **Primary Action:** Solid electric blue (`#3B82F6`) background, text `#FFFFFF`, font `Inter` 14px bold, `0.5rem` border radius, padding `0.75rem 1.5rem`. Hover shifts to `#2563EB` with data glow `0 0 20px -4px rgba(59, 130, 246, 0.5)`.
- **Secondary Technical:** Surface `#0F172A`, 1px solid `rgba(255, 255, 255, 0.12)`, text `#F8FAFC`. Hover: `rgba(255, 255, 255, 0.05)` fill and `rgba(59, 130, 246, 0.4)` border.
- **Ghost/Tertiary:** No fill, text `#94A3B8`, interactive hover text `#F8FAFC` accompanied by an inline directional arrow.

### Chips & Pill Badges
- **Status Badges:** Fully rounded (`rounded-full`), padding `0.25rem 0.75rem`, monospace tracking (`JetBrains Mono`, 11px uppercase). Dark background `rgba(59, 130, 246, 0.1)`, 1px border `rgba(59, 130, 246, 0.25)`, text `#60A5FA`. Includes a 6px pulsing pseudo-element dot for live states.
- **Filter Chips:** Height 32px, `rounded-full`, base `rgba(15, 23, 42, 0.6)` with `rgba(255, 255, 255, 0.08)` border. Selected state applies gradient outline from `#3B82F6` to `#6366F1`.

### Cards & Architecture Panels
- **System Specimen Card:** Base `#0F172A`, border `1px solid rgba(255, 255, 255, 0.08)`, radius `rounded-2xl` (16px) or `rounded-3xl` (24px) for hero features. Interior padding `2rem`.
- **Light Document Stage Panel:** Background `#F8FAFC`, border `1px solid rgba(15, 23, 42, 0.08)`, radius `rounded-2xl`. Internal modules utilize `#F1F5F9`.

### Input Fields
- Dark input wells: background `#070A11`, border `1px solid rgba(255, 255, 255, 0.1)`, radius `0.5rem`, text `#F8FAFC`, placeholder `#64748B`. Focused state: border `#3B82F6`, box-shadow `0 0 0 1px #3B82F6`.

### Checkboxes & Radios
- Box size 18px x 18px, base `#070A11`, border `1px solid rgba(255, 255, 255, 0.2)`, radius `4px` (checkbox) or `rounded-full` (radio). Checked state: fill `#3B82F6` featuring a sharp white checkmark glyph.

### Pipeline & Node Connectors
- Dedicated architecture component: horizontal or vertical hairline guides (`1px solid rgba(255, 255, 255, 0.1)`) intersected by status nodes with glow radii. In-flight transitions feature an animated linear gradient pulse spanning from `#3B82F6` to `#8B5CF6`.
